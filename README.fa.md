# کانکتور StreamForge برای Elasticsearch

این پروژه یک SinkConnector استاندارد Kafka Connect برای Elasticsearch 9 است.
شناسه سند قطعی، پردازش Bulk با تأیید سطح آیتم و Offset امن و پیوسته دارد.

این نسخه برای انتشار عمومی پیاده‌سازی موجود آماده شده است؛ هیچ نتیجه‌ای درباره
کارایی یا آمادگی تولیدی عمومی اعلام نمی‌کند. برای جزئیات، راهنمای انگلیسی و
یادداشت‌های انتشار را ببینید.
