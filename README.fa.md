# کانکتور StreamForge برای Elasticsearch

این پروژه یک SinkConnector استاندارد Kafka Connect برای Elasticsearch 9 است.
شناسه سند قطعی، پردازش Bulk با تأیید سطح آیتم و Offset امن و پیوسته دارد.

این نسخه برای انتشار عمومی پیاده‌سازی موجود آماده شده است؛ هیچ نتیجه‌ای درباره
کارایی یا آمادگی تولیدی عمومی اعلام نمی‌کند. برای جزئیات، راهنمای انگلیسی و
یادداشت‌های انتشار را ببینید.

## استفاده واقعی

کانکتور StreamForge Elasticsearch Sink توسط امیرحسین باقری توسعه داده شده و
در بخشی از زیرساخت پلتفرم DataPie مورد استفاده قرار گرفته است.

استفاده در DataPie یک نمونه عملیاتی واقعی برای بررسی رفتار، استقرار و
دریافت بازخوردهای زیرساختی این کانکتور بوده است.

این پروژه مستقل از DataPie منتشر شده و برای استفاده در هر محیط سازگار با
Kafka Connect طراحی شده است.

برای استفاده از این کانکتور نیازی به نصب یا وابستگی به DataPie وجود ندارد.
