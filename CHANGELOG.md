# Changelog

## [1.0.0] - 2026-08-23

The first public release of the production-tested connector implementation.

This release packages the existing Kafka Connect Elasticsearch sink without
changing connector logic, defaults, dependency versions, Java compatibility,
or artifact coordinates. It adds public-facing documentation for architecture,
installation, configuration, standalone/Docker/Kubernetes deployment,
operations, troubleshooting, development, and the benchmark evidence currently
available in the repository.

Known limitations are listed in [RELEASE_NOTES.md](RELEASE_NOTES.md).
